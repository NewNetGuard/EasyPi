# Promoted TLS Endpoint Bridge source

This package was promoted from the managed EasyPi Mobile experiment at commit
ba391c58e0852881af1f7f09d997a339ffa2a8f1. Runtime modules only are included; profiles, captures, keys,
measurements, generated fixtures and build artifacts were not copied.

and an explicit source/frozen administrative entrypoint. This server copy is the
runtime implementation for EasyPi releases. See docs/PRISM_TLS_ENDPOINT_BRIDGE.md.
